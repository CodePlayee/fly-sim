# flySim — Web3D 模拟飞行（免费全球地形，无需 token）

用 Web3D 技术尽量还原《微软模拟飞行》的核心体验：**真实全球 3D 地形、卫星影像、大气、随真实时间变化的太阳/月亮光照**，支持从 3 个世界知名国际机场起降。

> **完全免费**：不需要任何 token / API key / 登录。

## 技术方案

| 模块 | 方案 | 是否需 key |
|------|------|-----------|
| 渲染引擎 | **MapLibre GL JS**（开源） | 否 |
| 全球高程地形 | **AWS 开放数据集 Terrarium DEM**（`elevation-tiles-prod`） | 否 |
| 卫星影像 | **Esri World Imagery** | 否 |
| 天空大气 | MapLibre `setSky` | 否 |
| 太阳/月亮位置与光照 | **SunCalc**（纯本地天文计算） | 否 |

MapLibre 原生支持 `raster-dem` 地形，自动 LOD / 流式加载全球真实高程，无需自建瓦片管线。

## 运行

```bash
npm install
npm run dev      # http://127.0.0.1:5273/
npm run shot     # 生成 shots/*.png 截图验证
```

### 操作

| 按键 | 功能 |
|------|------|
| ↑ / ↓ | 俯仰（拉杆/推杆） |
| ← / → | 滚转 |
| W / S | 加/减油门 |
| A / D | 方向舵 |
| V | 切换追尾/座舱视角 |

起飞：W 加满油门，空速达约 117 kt 后拉 ↑ 抬轮。右上角可切换机场、拖动滑块改当地时间看昼夜光照、或点"真实当前时间"。

## 光照说明

SunCalc 按机场真实经纬度 + 时刻计算太阳/月亮的方位角与高度角，驱动：
- 天空与地平线大气配色（白天蓝天 / 黄昏金光 / 暮光蓝调 / 夜晚暗蓝）
- 山体阴影的照射方向（随太阳/夜间月亮方位旋转）
- 卫星影像整体明暗 + 夜间压暗叠层

经像素亮度实测，昼夜单调正确：正午最亮 → 黄昏 → 夜晚最暗。

## 飞机模型

`boeing737.js` 用纯程序化方式（圆柱机身 + 椭球机头 + 后掠机翼 + 翼梢小翼 +
吊挂发动机 + 后掠垂尾，带蓝色涂装），**不依赖任何外部模型文件**，
生成一架可辨识的 737 风格客机。

**可动部件（随操纵实时动画）**：副翼（随滚转差动偏转）、升降舵（随俯仰）、
方向舵（随偏航/转弯）、发动机风扇（随油门旋转）。各舵面以铰链枢轴贴合后缘，
由 `group.userData.controls` 暴露，叠层每帧按飞行状态平滑驱动。

渲染采用**独立透明 Three.js 画布叠加在地图前景**的方案：追尾/座舱视角下飞机
始终是最近物体，应永远在前景，无需与地形做深度合成或地理投影，更稳健。
模型受光与 SunCalc 计算的太阳方位/高度同步。

## 飞行动力学

`aircraft.js` 是一套**点质量 + 姿态的简化 6-DOF**飞行模型（"街机增强"档），
用力/力矩积分而非运动学衰减，真实感来源是**带攻角(AoA)的升力曲线**：

- 升力 `L = ½ρV²S·CL(α)`，CL 随攻角线性增长，**超过失速角(16°)后骤降**
- 阻力极曲线 `CD = CD0 + k·CL²`（含诱导阻力），随高度的空气密度衰减
- 纵向：`dV/dt = (推力−阻力)/m − g·sinγ`（速度↔高度能量耦合）
- 法向：航迹角 γ 由升力与重力分量积分；**协调转弯**由坡度的水平升力分量改变航向
- **失速**：升降舵失效 + 自然低头力矩，自动趋向改出（机头下俯减小攻角）
- **自动回稳**（按需）：松杆后滚转归零、俯仰趋向当前速度的平飞配平；
  配平**坡度自适应**，转弯时自动多拉杆维持高度
- HUD 显示实时**过载(g)**与**失速告警**

> 为何不用通用物理引擎：Rapier/Cannon/Ammo 等只做刚体/碰撞，**不含空气动力学**
> （真实感的全部来源仍需自写）；且本项目在地理坐标（经纬度+大圆推进）中运动，
> 与引擎的局部笛卡尔空间存在坐标系阻抗。自研在现有框架内零依赖、可逐项调参。

## 近地警告系统（GPWS）

`gpws.js` 模拟真实飞机的近地警告。它沿**预测航迹**（按当前航向、地速、垂直
速度向前外推 30 秒）逐点用 `map.queryTerrainElevation` 采样地形高度，计算预测
路径相对地形的最小离地余量与撞地剩余时间，分级告警：

| 等级 | 触发条件 | 显示 |
|------|---------|------|
| 安全 | 预测路径离地 > 150m | 无 |
| 警戒 caution | 预测离地 ≤ 150m 或撞地 ≤ 22s | 黄色 **"TERRAIN AHEAD"** 横幅 + 黄色屏幕边缘闪烁 |
| 警告 warning | 预测离地 ≤ 60m 或撞地 ≤ 12s | 红色 **"PULL UP ▲"** 横幅 + 红色屏幕边缘急闪 |

HUD 仪表盘新增"离地(AGL)"实时读数，并随告警等级变色。关键在于它是**预测式**
的：即使当前正下方还有余量，只要前方航迹会撞山就会提前告警。

## 导航小地图（ND）

`minimap.js` 在右下角绘制一个圆形导航显示（北朝上）：
- **已飞航迹**（绿色线）——实时记录飞行路径
- **机场**（黄色=出发机场，蓝色=其它；超出量程时夹到边缘作方向指示）
- **到目标的航线**（品红虚线）+ 目标符号，左上角显示**方位 / 相对转向(左/右N°) / 距离**
- **本机符号**（中心三角，按航向旋转）+ 航向矢量
- **距离环 + 量程自适应**（1–10000km，保证出发机场与目标都在画面内）

**航点导航**：默认目标为最近的其它机场；**单击小地图**可设定自定义航点(WPT)，
航线、方位、距离随之更新；**双击**清除自定义航点回到默认目标机场。

纯 2D canvas 实现，无额外依赖；切换机场时航迹与航点自动清空。
